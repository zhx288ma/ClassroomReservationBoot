## 一键启动

```bash
cd ClassroomReservationBoot
docker compose -f docker-compose.middleware.yml up -d
```

然后在 IDEA 中运行 `ClassroomReservationBootApplication`。当前开发阶段不要执行 `docker compose up -d --build`，否则会尝试构建 app 镜像并拉取 Maven/JDK 基础镜像，网络不稳定时容易失败。

访问：

```text
Swagger: http://localhost:8081/swagger-ui.html
Actuator: http://localhost:8081/actuator/health
RabbitMQ 控制台: http://localhost:15672
```

RabbitMQ 控制台默认账号：

```text
guest / guest
```

默认账号：

```text

普通用户: 17715993804 / 123456
```

## 本地 Maven 启动

```bash
mvn clean package
java -jar target/classroom-reservation-boot-2.0.0.jar
```

## 核心接口流程

1. `/auth/login` 登录，复制返回的 token。
2. 后续接口 Header 携带 `X-Token: {token}`。
3. `/advisor/recommend` 获取可解释推荐。
4. `/reservations/submit-token` 获取一次性提交令牌。
5. `/reservations` Header 携带 `X-Submit-Token` 发起预约。
6. `/reservations/{orderId}/cancel` 取消预约，触发候补补位。
7. `/reservations/sign` 签到。
8. `/reservations/dashboard` 查看统计看板。

## 运维演示接口

```text
GET /ops/redis/overview
GET /ops/redis/stock?roomId=1&reserveDate=2026-06-01&timeSlot=18:00-20:00
POST /ops/redis/stock/sync
GET /ops/redis/hot-rooms
GET /ops/mq/overview
GET /actuator/health
GET /actuator/metrics
```

`/ops/**` 和 `/actuator/metrics` 默认也走登录拦截器，先登录后在 Header 携带 `X-Token`。`/actuator/health` 可以直接访问，适合做健康检查。

## 面试时可以强调

这不是在旧 SSM 项目里“加几个依赖”，而是把项目重构成独立 Spring Boot 服务：

```text
SSM + JSP 单体后台 -> Spring Boot RESTful 服务
Session 登录 -> Redis Token 登录态
同步预约 -> Redis Lua 预扣库存 + MySQL 事务兜底
普通取消 -> Redisson 锁 + 候补补位
同步通知 -> RabbitMQ 异步站内信 + 重试 + 死信队列
手写接口文档 -> Swagger OpenAPI
手工演示 -> Docker Compose + Actuator + JMeter 压测脚本
```
