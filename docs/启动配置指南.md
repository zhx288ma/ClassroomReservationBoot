# 项目启动配置说明

本文档只回答一个问题：你要把 `ClassroomReservationBoot` 启动起来，电脑上需要准备什么、项目里哪些配置要看、启动后怎么验证。

推荐当前开发阶段使用“Docker 启动中间件 + IDEA 启动 Spring Boot”。这样不需要 Docker 构建应用镜像，也能避开 Docker Hub 拉取 Maven/JDK 基础镜像失败的问题。

## 1. 项目目录

```text
D:/A_project/crs/ClassroomReservationBoot
```

后续所有命令默认都在这个目录执行：

```bash
cd D:/A_project/crs/ClassroomReservationBoot
```

## 2. 启动前需要安装什么

### 方式一：Docker 启动中间件 + IDEA 启动应用，推荐

本机只需要：

```text
Docker Desktop
IDEA
```

不强制要求本机安装 MySQL、Redis、RabbitMQ，因为这些都会由 Docker 容器提供。Spring Boot 应用直接在 IDEA 中运行。

相关文件：

```text
docker-compose.middleware.yml
```

### 方式二：本地 Maven 启动

本机需要：

```text
JDK 11
Maven 3.8+
MySQL 8.0
Redis 7.x
RabbitMQ 3.x
```

本地 Maven 启动适合调试，但你要自己保证 MySQL、Redis、RabbitMQ 已经启动，并且账号、端口和 `application.yml` 对得上。

## 3. 默认端口

| 服务 | 端口 | 访问方式 |
| --- | --- | --- |
| Spring Boot 应用 | `8081` | `http://localhost:8081` |
| Swagger | `8081` | `http://localhost:8081/swagger-ui.html` |
| Actuator Health | `8081` | `http://localhost:8081/actuator/health` |
| MySQL | `3306` | `localhost:3306` |
| Redis | `6379` | `localhost:6379` |
| RabbitMQ | `5672` | 应用连接端口 |
| RabbitMQ 控制台 | `15672` | `http://localhost:15672` |

如果你的电脑上已经有 MySQL、Redis 或 RabbitMQ 占用了这些端口，需要先停止本机服务，或者修改 `docker-compose.yml` 的端口映射。

## 4. Docker Compose 启动配置

Docker Compose 会启动四个容器：

```text
classroom-mysql
classroom-redis
classroom-rabbitmq
classroom-app
```

配置位置：

```text
docker-compose.yml
```

### MySQL 配置

```text
MYSQL_ROOT_PASSWORD: 123456
MYSQL_DATABASE: classroom_reservation
端口: 3306
数据卷: mysql-data
```

应用连接 MySQL 的环境变量：

```text
MYSQL_HOST=mysql
MYSQL_PORT=3306
MYSQL_DATABASE=classroom_reservation
MYSQL_USERNAME=root
MYSQL_PASSWORD=123456
```

### Redis 配置

```text
镜像: redis:7
端口: 6379
持久化: AOF
数据卷: redis-data
```

应用连接 Redis 的环境变量：

```text
REDIS_HOST=redis
REDIS_PORT=6379
```

Redis 不需要手动建表。登录 token、库存、排行榜、签到 BitMap 等 key 会在业务运行时自动写入。

### RabbitMQ 配置

```text
镜像: rabbitmq:3.13-management
连接端口: 5672
控制台端口: 15672
账号: guest
密码: guest
```

应用连接 RabbitMQ 的环境变量：

```text
RABBITMQ_HOST=rabbitmq
RABBITMQ_PORT=5672
RABBITMQ_USERNAME=guest
RABBITMQ_PASSWORD=guest
```

项目启动后会自动声明交换机、队列、死信队列：

```text
classroom.reserve.exchange
classroom.reserve.notify.queue
classroom.reserve.dlx
classroom.reserve.notify.dlq
```

如果你之前启动过旧版本 RabbitMQ，可能已经存在没有死信参数的同名队列。RabbitMQ 不允许用不同参数重复声明队列，这时可以进入 RabbitMQ 控制台删除 `classroom.reserve.notify.queue`，再重启应用。

## 5. 一键启动命令

当前推荐只启动中间件：

```bash
docker compose -f docker-compose.middleware.yml up -d
```

查看容器状态：

```bash
docker compose -f docker-compose.middleware.yml ps
```

然后在 IDEA 中运行：

```text
com.xuan.boot.ClassroomReservationBootApplication
```

停止项目：

```bash
docker compose -f docker-compose.middleware.yml down
```

如果你要连数据卷也一起清掉，慎用：

```bash
docker compose -f docker-compose.middleware.yml down -v
```

`-v` 会删除 MySQL 和 Redis 的持久化数据，演示数据会被清空。

## 6. 启动后怎么验证

### 1. 看健康检查

```text
http://localhost:8081/actuator/health
```

正常应该能看到整体状态是 `UP`，并包含数据库、Redis、RabbitMQ 等健康信息。

### 2. 打开 Swagger

```text
http://localhost:8081/swagger-ui.html
```

Swagger 能打开，说明应用已经正常对外提供接口。

### 3. 打开 RabbitMQ 控制台

```text
http://localhost:15672
guest / guest
```

重点查看：

```text
Exchanges:
classroom.reserve.exchange
classroom.reserve.dlx

Queues:
classroom.reserve.notify.queue
classroom.reserve.notify.dlq
```

### 4. 登录默认账号

默认账号来自：

```text
src/main/resources/data.sql
```

账号：

```text
管理员: 19901541686 / 123456
普通用户: 17715993804 / 123456
```

登录接口：

```text
POST /auth/login
```

后续接口在 Header 携带：

```text
X-Token: 登录返回的 token
```

## 7. 本地 Maven 启动怎么配

如果不用 Docker 运行应用，而是在本机或 IDE 启动 Spring Boot，需要准备 MySQL、Redis、RabbitMQ。

### MySQL

创建数据库：

```sql
CREATE DATABASE classroom_reservation DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

默认连接配置：

```text
host: localhost
port: 3306
database: classroom_reservation
username: root
password: 123456
```

对应配置：

```text
src/main/resources/application.yml
```

项目启动时会执行：

```text
src/main/resources/schema.sql
src/main/resources/data.sql
```

所以一般不需要你手动建表。

### Redis

默认连接配置：

```text
host: localhost
port: 6379
password: 空
database: 0
```

只要 Redis 服务启动即可，不需要预先写入任何 key。

### RabbitMQ

默认连接配置：

```text
host: localhost
port: 5672
username: guest
password: guest
```

控制台：

```text
http://localhost:15672
```

应用启动后会自动创建 exchange、queue 和 dlq。

### 启动命令

```bash
mvn clean package
java -jar target/classroom-reservation-boot-2.0.0.jar
```

或者在 IDE 中直接运行：

```text
com.xuan.boot.ClassroomReservationBootApplication
```

## 8. 可以覆盖的环境变量

`application.yml` 已经写了默认值，也支持环境变量覆盖：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `MYSQL_HOST` | `localhost` | MySQL 地址 |
| `MYSQL_PORT` | `3306` | MySQL 端口 |
| `MYSQL_DATABASE` | `classroom_reservation` | 数据库名 |
| `MYSQL_USERNAME` | `root` | MySQL 用户名 |
| `MYSQL_PASSWORD` | `123456` | MySQL 密码 |
| `REDIS_HOST` | `localhost` | Redis 地址 |
| `REDIS_PORT` | `6379` | Redis 端口 |
| `RABBITMQ_HOST` | `localhost` | RabbitMQ 地址 |
| `RABBITMQ_PORT` | `5672` | RabbitMQ 端口 |
| `RABBITMQ_USERNAME` | `guest` | RabbitMQ 用户名 |
| `RABBITMQ_PASSWORD` | `guest` | RabbitMQ 密码 |

Docker Compose 启动时，这些变量已经在 `docker-compose.yml` 里配置好了。

## 9. 推荐演示流程

1. 启动：

```bash
docker compose -f docker-compose.middleware.yml up -d
```

2. 打开健康检查：

```text
http://localhost:8081/actuator/health
```

3. 打开 Swagger：

```text
http://localhost:8081/swagger-ui.html
```

4. 调用 `/auth/login` 登录，复制 token。

5. 调用 `/advisor/recommend` 看智能推荐。

6. 调用 `/reservations/submit-token` 获取提交 token。

7. 调用 `/reservations` 发起预约，Header 里带：

```text
X-Token: 登录 token
X-Submit-Token: 提交 token
```

8. 调用运维接口：

```text
GET /ops/redis/overview
GET /ops/redis/stock?roomId=1&reserveDate=2026-06-01&timeSlot=18:00-20:00
GET /ops/mq/overview
```

这些 `/ops/**` 接口需要 `X-Token`。

## 10. 常见启动问题

### 端口被占用

现象：

```text
Bind for 0.0.0.0:3306 failed
Bind for 0.0.0.0:6379 failed
Bind for 0.0.0.0:8081 failed
```

处理：

```text
停止本机已有 MySQL/Redis/RabbitMQ/Java 应用；
或者修改 docker-compose.yml 的端口映射。
```

### MySQL 连接失败

重点检查：

```text
docker compose ps
docker compose logs mysql
MYSQL_PASSWORD 是否是 123456
数据库名是否是 classroom_reservation
```

### Redis 连接失败

重点检查：

```text
docker compose ps
docker compose logs redis
REDIS_HOST 是否为 redis（Docker 内）
REDIS_PORT 是否为 6379
```

### RabbitMQ 队列声明失败

如果日志里出现类似队列参数不一致，通常是旧队列已经存在：

```text
inequivalent arg 'x-dead-letter-exchange'
```

处理方式：

```text
打开 http://localhost:15672
删除 classroom.reserve.notify.queue
重启 app 容器
```

重启 app：

```bash
docker compose restart app
```

### Docker 构建下载依赖很慢

第一次执行 `docker compose up -d --build` 会下载 Maven 依赖和 Docker 镜像，时间可能比较久。后续有缓存会快很多。

### Swagger 打不开

先看：

```text
http://localhost:8081/actuator/health
```

如果 health 也打不开，说明应用没启动成功，继续看应用日志：

```bash
docker compose logs -f app
```

## 11. 当前环境提醒

我在当前这台环境里检查过，命令行没有识别到：

```text
mvn
java
docker
jmeter
```

所以如果你要在这台电脑直接启动，需要先安装 Docker Desktop；如果选择本地 Maven 启动，还要安装 JDK 11 和 Maven。最省事的路径是安装 Docker Desktop 后直接用 Docker Compose 启动。
