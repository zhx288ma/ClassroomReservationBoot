# 压测报告

## 压测目标

验证热门教室高并发预约接口在 Redis Lua 预扣库存、MySQL 唯一索引兜底、Redisson 锁和 RabbitMQ 异步通知下的表现。

## 环境

```text
应用: Spring Boot 2.7.18
JDK: 11
数据库: MySQL 8.0
缓存: Redis 7
消息队列: RabbitMQ 3.13
压测工具: JMeter 5.x
部署方式: Docker Compose
```

## 测试脚本

```text
jmeter/classroom-reservation-load-test.jmx
```

## 运行命令

```powershell
.\jmeter\run-load-test.ps1 -InitUsers -ReserveDate 2026-06-01 -TimeSlot "18:00-20:00"
```

## 场景设计

```text
线程数: 200
Ramp-Up: 20s
循环次数: 1
核心链路:
1. 登录获取 X-Token
2. 获取一次性 X-Submit-Token
3. 并发提交同一教室同一时间段预约
```

## 压测数据准备

先初始化 200 个压测用户：

```powershell
Get-Content -Raw .\jmeter\loadtest-users.sql | docker exec -i classroom-mysql mysql -uroot -p123456 classroom_reservation
```

JMeter 脚本使用 `18800000001` 到 `18800000200` 这 200 个用户，密码均为 `123456`。

## 重点观察指标

```text
吞吐量 TPS
平均响应时间
P95 响应时间
错误率
MySQL tb_reserve_order 是否只有一个成功预约
Redis reserve:stock 是否不小于 0
RabbitMQ 通知队列是否正常消费
```

## 验收标准

```text
1. 同一 roomId + reserveDate + timeSlot 不出现超卖。
2. 同一用户同一时间段不出现重复活跃预约。
3. 库存不足时返回失败或进入候补队列。
4. 取消预约后库存回滚，并优先触发候补补位。
5. 错误率主要来自业务失败，不应出现大量 500。
```
